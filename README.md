# [Microsoft Ignite 2026](https://ignite.microsoft.com)

## 🔥LAB681: Turn signal into real-time protections with Project Perception
### Session description

Get hands-on with Project Perception and see how agentic security helps teams understand risk faster and turn insights into protection. Learn how Red team, Blue team, and Green team agents work together to defend at machine speed.

### 🚀 Getting started

#### In a guided session

If you're following along during a live session:

The lab guide is built into Skillable. 

#### On your own

If you're learning at your own pace:

You can find directions in the /Data folder in the repository along with some example agent output files. 

### 🎯 Learning outcomes

By the end of this session, you will be able to:

- Explain how Red team, Blue team, and Green team agents work together in Project Perception
- Use Project Perception to understand security risk from signals
- Turn Project Perception insights into real-time protections

### 💻 Technologies used

- Microsoft Perception
- Microsoft Defender
